# Next.js Starter

A Bun-first Next.js template for full-stack developers and small teams.

## Language

**Starter**:
The repository developers clone to begin an App. It is the product, not an App itself.
_Avoid_: boilerplate, scaffold, skeleton

**App**:
A project created from the Starter and developed as its own product.
_Avoid_: project, product, site

**Template**:
The distribution format of the Starter: a repository marked "Use this template". Not a synonym for the Starter itself.
_Avoid_: boilerplate

**Showcase**:
The Starter's root-route demonstration of the stack, quickstart, and theme toggle. It ships with the Starter, and the Strip Step removes it.
_Avoid_: demo, landing page, homepage

**Strip Step**:
The documented procedure that turns the Starter into an App: it deletes the Showcase and replaces the root route, its test, and the site resource's showcase copy.
_Avoid_: strip script, eject, scaffold
